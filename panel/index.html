Image Guard

Keeps every model request under the provider's image limit before it is sent.

Statusactive
Modelmistral/deepseek-v4-1-flash-1017
Keeps newest15 images
Log~/.local/share/opencode/log/image-guard.log

What it does

  • Counts image parts across the whole request, including screenshots returned by tools.
  • Keeps the newest 15 and replaces older ones with a short text placeholder naming the file.
  • Changes only the outgoing request. Stored history, search and memory are untouched.

Configure

OPENCODE_MAX_IMAGES15
IMAGE_GUARD_MODELScomma-separated provider/model

Set these on the OpenCode server's environment, then reload the plugin. The default is tuned for Mistral's 20-image limit; keep the cap below it.

Works alongside context-management plugins such as Magic Context. Removing or disabling this extension removes the OpenCode plugin with it.
